> [!SUMMARY]
> Downloads are optional. Skip this whole section if you only watch files you already have. Set it up if you want Fliks to find and fetch missing titles for you.

## Who needs this

**You need it** if you want to request a movie, a show, a book or an album and have Fliks search for it through indexers, hand it to a download client and file it into your library.

**You can skip it** if you watch your own files. Playback, subtitles, libraries and users never read the settings in this section. Dismiss the quality profile and auto-approval items of the setup checklist on **Settings > General** with the cross.

## Order to set things up

1. [Quality profile](/downloads/quality-profiles): which qualities are acceptable and how they rank. Tune them later with [quality definitions](/downloads/quality-definitions) and [custom formats](/downloads/custom-formats).
2. [Language profile](/administration/language-profiles): accepted audio languages, plus the subtitle languages to fetch.
3. Pick both as the defaults of your library: **Settings > Libraries**, open the library, **Default quality profile** and **Default language profile**. A title with no quality profile is never searched. See [Quality and language profiles](/features/libraries#quality-and-language-profiles).

   ![The library settings: Default quality profile and Default language profile](/img/download-library-profiles.webp)
4. [Download plugin](/downloads/plugin): install it, nothing is downloaded without it.
5. [Indexers](/downloads/indexers): where releases are searched.
6. [Download client](/downloads/download-clients): qBittorrent or Transmission, and the shared folder.
7. [Requests](/downloads/requests): how people ask for titles and who approves them.
8. [Auto-approval](/downloads/auto-approval): rules that approve requests without an administrator.
9. [Automatic search](/downloads/automatic-search): how often Fliks looks again for missing and upgradable titles.

When something does not move, go to [Download troubleshooting](/downloads/troubleshooting).
